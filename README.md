# 机器人没有「互联网」· 具身智能数据采集与遥操作学习站

一个纯静态的中文学习网站，把两期 B 站视频拆解成一条可以按顺序读下去的数据工程知识路径。

## 打开方式

直接双击 `index.html` 即可（无需服务器、无需联网）。
**所有 25 张图片与 2 张示意图都已内嵌进 HTML**（base64），因此单个文件拷到任何地方、发给任何人都能正常显示。

## 交互

- 顶部导航 12 个入口 + 首页两个按钮，点击后**直接跳转到对应章节**（脚本计算位置，不依赖浏览器锚点）。
- 四层金字塔：点击任意一层，右侧面板切换该层的质量/成本/规模与优缺点。
- 采集路线 Tab：动捕 / UMI / 重定向三个面板。
- 台词库：关键词搜索（高亮）、按视频来源筛选、时间戳直达 B 站。
- 小测验：选择后判分，并展开解析。

## 文件说明

- `index.html`：网站全部内容（结构、样式、交互、图片）都在这一个文件里。
- `transcript.js`：台词数据（`window.TX_DATA`），与主文件分离，便于替换。
- `README.md`：本文件。

## 关于台词转写

- 音频：B 站公开视频音轨。
- 转写：本地 `faster-whisper large-v3-turbo`（int8, CPU），配合领域词表（hotwords）。
- 后处理：繁简转换、术语纠错（遥操 / 具身 / 觅蜂 / Sharpa / 众包 / 夹爪 等）、按句切分与章节归档。
- 语音转写难免有个别错字，引用请以原视频为准。
